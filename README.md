# PDF 日付・文字 追記ツール

図面PDFに「文字＋日付」（例：作成中 2026.11.24）を赤字で追記するブラウザ用ツールです。
処理はすべてブラウザ内で行い、PDFを外部に送信しません。

## ファイル

| ファイル | 内容 |
|---|---|
| `PDF日付文字追記ツール_オフライン版.html` | 1ファイルで完結。ダブルクリックでEdge／Chromeで開いて使う（ネット接続不要） |
| `index.html` ＋ `cmaps.js` | Web公開用（GitHub Pages など）。ライブラリはCDNから読み込む |

## 主な機能

- 文字・日付・書式（2026.11.24／令和8年…など）を先に設定し、PDFをドロップして追記
- 対象ページ：全ページ／表紙を除く／指定（例：2-10, 15）
- 色・大きさ・書体（HGP創英角ゴシックUBなど）、枠囲み、白背景
- 位置はドラッグで指定（ページに対する割合で記録。A3・A4混在でも同じ相対位置）
- 自動ずらし：下の図枠の中で文字と重ならない位置へ移動（罫線は重なってOK）
  - 空きがない場合：間隔を詰める → 80%・65%に縮小 → 図枠外の余白 → 指定位置のまま
- 保存前の確認：調整したページを一覧表示し、ドラッグ・大きさ変更で手動調整できる
- 複数PDFはZIPでまとめて保存。ファイル名末尾の日付（8桁）を新しい日付に差し替え可能
